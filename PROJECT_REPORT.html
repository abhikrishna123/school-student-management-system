1. Executive Summary & Architecture Report

The School Student Management System is an enterprise academic administration portal engineered to unify student lifecycle onboarding, curriculum master cataloging, continuous internal evaluations (CIE), and daily classroom attendance tracking. Traditional educational workflows suffer from fragmented record-keeping across spreadsheets, manual tally errors during report card generation, and loss of historical attendance records. This project resolves those inefficiencies by deploying a high-availability, responsive single-page architecture powered by the MERN (MongoDB, Express, React, Node.js) stack.

Architectural Design & High-Level Data Flow

The system is constructed with strict separation of concerns across 3 resilient tiers:

  • Frontend Tier (React 19 + Vite + Tailwind CSS): Delivers zero-latency client-side view switching, reactive modal dialogues, instant client-side search filtering, and clean responsive CSS styling.
  • Serverless API Tier (Node.js + Express.js + Netlify Functions): Routes all requests through an Express REST engine adapted for AWS Lambda serverless execution. Employs middleware route normalizers, Mongoose ODM schemas, and robust mathematical grade computation engines.
  • Database Tier (MongoDB Atlas Cloud Cluster): Stores persistent records in cloud-hosted multi-replica document collections (Students, Subjects, Marks, Attendance) with automated TLS/SSL encryption and intelligent in-memory simulation failover.

function calculateGrade(percentage: number, hasFailedSubject: boolean): { grade: string; status: string } { if (hasFailedSubject || percentage < 35) { return { grade: 'F', status: 'Fail' }; } if (percentage >= 90) return { grade: 'A+', status: 'Pass' }; if (percentage >= 80) return { grade: 'A', status: 'Pass' }; if (percentage >= 70) return { grade: 'B', status: 'Pass' }; if (percentage >= 60) return { grade: 'C', status: 'Pass' }; if (percentage >= 50) return { grade: 'D', status: 'Pass' }; return { grade: 'E', status: 'Pass' }; }
